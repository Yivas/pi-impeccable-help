# Code of conduct

Treat people respectfully in issues, pull requests, and any space where you represent this project. Critique the work rather than the person. Explain disagreements, accept corrections, and respect different levels of experience.

Harassment, threats, discriminatory language, sexualized content, doxxing, repeated unwanted contact, and deliberate disclosure of private information are not acceptable. Do not repost removed content or pressure contributors to disclose personal information.

Yivas moderates this repository and may edit or remove content, lock a conversation, restrict participation, or block an account when needed. Responses depend on the behavior and its impact; warnings are not required for threats or exposed private information.

To report abuse without repeating it publicly, use GitHub's **Report content** action on the relevant issue, comment, or pull request, or [contact GitHub Support](https://support.github.com/contact) if the normal reporting control is unavailable. Include the relevant URL, not a public copy of sensitive content. These reports go to GitHub, not to a private project inbox. For security defects in the extension, use the separate channel in [SECURITY.md](SECURITY.md).
